# StayOnBeat 产品与交互设计文档

> 状态：草案 v0.2（仅文档，暂不编码）
> 参考：https://metronome-online.com/zh
> 一句话定义：为“工作间隙无法练琴的人”设计的在线节奏训练器，像节拍器一样稳定，像音游一样即时反馈。

## 1. 产品定义

StayOnBeat 是一个纯浏览器端的节奏训练工具。用户在节拍器的律动下，通过键盘或鼠标点击来跟随节拍，系统实时给出命中判定、连击与匹配度，帮助用户在办公室等受限环境中保持节奏感。

### 1.1 核心价值

- **时间轻**：5 分钟以内即可完成一次有效训练。
- **反馈快**：每次点击立即看到 Perfect/Great/Good/Miss 和匹配度。
- **场景隐蔽**：支持静音/仅视觉模式，不打扰同事。
- **无门槛**：打开网页即可用，无需注册、下载或外部设备。

### 1.2 与参考站的关系

参考站解决的是“给我一个稳定的节拍器”；StayOnBeat 在其基础上增加“我来跟这个节拍”。因此基础节拍器能力要对齐，训练评分是差异化的新增层。

## 2. 目标用户与场景

| 用户画像 | 核心需求 | 典型场景 |
| --- | --- | --- |
| 上班族吉他/钢琴爱好者 | 工作间隙保持手指与节奏感 | 午休、会议间隙用键盘点击训练 |
| 初学者鼓手/乐手 | 建立稳定拍感 | 手机上做 2 分钟跟拍练习 |
| 音乐教师/陪练 | 给学员布置节奏作业 | 使用 Tap BPM 快速确认速度并示范 |
| 普通音乐爱好者 | 娱乐化节奏挑战 | 空闲时用连击/评分获得游戏感 |

### 2.1 主场景：办公室无声训练

用户打开页面 → 默认进入静音/仅视觉模式 → 设置 BPM=90 → 确认当前为“训练”模式（默认） → 点击“开始训练” → 开始 1 小节倒计时 → 跟随屏幕脉冲点击空格键 → 实时看到命中与匹配度 → 60 秒后进入总结 → 保存记录并重试。

## 4. 功能范围

### 4.1 MVP（必须）

- 双模式：默认“训练”模式；可切换到“节拍器”模式仅播放节拍，不计分。
- 节拍器：BPM 1–240（默认 120），+/- 与滑块调整；训练推荐常用区间可额外提供快捷预设。
- 拍号：1–12 拍，默认 4。
- 重音：第一拍可选。
- 细分：四分、八分、三连音、十六分。
- 计时器：15s/30s/60s/120s 快捷 + 自定义。
- Tap BPM。
- 声音开关与音量。
- 亮/暗主题，默认暗色。
- 训练模式：键盘/鼠标点击、实时判定、连击、匹配度、早期/晚期反馈。
- 会话总结与本地历史记录。
- 静音/仅视觉节拍模式。

### 4.2 P1（增强）

- 输入延迟校准。
- 训练难度档位：入门/标准/严格，对应判定窗口缩放。
- 随机节奏型训练。
- 每日打卡与历史趋势图。
- 移动端触觉反馈（如设备支持）。

### 4.3 P2（后续）

- 账号、云同步、排行榜。
- 自定义节拍模式编辑器。
- 多语言。
- PWA 离线安装。

## 6. 核心用户流程

### 6.1 快速开始

```text
打开页面
  → 调整 BPM（或 Tap BPM）
  → 确认当前为“训练”模式（默认）
  → 点击“开始训练”
  → 可选 count-in
  → 跟随节拍点击
  → 结束/计时器到点
  → 查看总结
  → 重试
```

### 6.2 设置优先流程

```text
打开页面
  → 展开设置：拍号、细分、计时器、音量、主题
  → 开始训练
```

### 6.3 静音训练流程

```text
打开页面
  → 默认静音，仅视觉节拍
  → 视觉节拍提示增强
  → 键盘点击
  → 结束后可选择开启声音复听
```

## 8. 关键交互设计

### 8.1 开始训练前

- 顶部提供“节拍器 / 训练”模式切换；默认“训练”模式。
- 训练模式的 CTA 为“开始训练”；节拍器模式 CTA 为“开始”，仅播放节拍。
- 首次进入默认暗色 + 静音/仅视觉节拍；开启声音后默认音量 0.5，之后记住用户音量。
- Tap BPM：用户至少点击 4 次后给出估算 BPM，并提示可一键进入当前模式的开始流程。

### 8.2 Count-in（训练模式）

- 训练开始前可显示 1 小节倒计时，默认开启。
- 倒计时使用“1-2-3-4”或节拍灯闪烁，用户明确从哪一拍开始。

### 8.3 训练中

- 键盘焦点不必固定在输入框；全局监听空格/回车，防止页面滚动。
- 鼠标用户点击中央 TrainingPad，Pad 在按下时收缩、命中判定弹出。
- 每拍预期时间到来时，节拍灯点亮；未静音时同时播放音频脉冲。用户点击后生成判定。
- 判定反馈从点击位置浮出并快速消失，不影响下一拍。

### 8.4 结束与总结（训练模式）

- 计时器到点或用户点击停止后，立即进入 Summary。
- 总结页默认聚焦“匹配度”大数字，然后是评级和明细。
- “再来一次”保留本次设置；更改设置则回到配置状态。

## 9. 判定与评分 UX

### 9.1 判定呈现

| 判定 | 中文 | 颜色 | 文案建议 |
| --- | --- | --- | --- |
| Perfect | 完美 | 金色 `#FFD166` | “节奏完美！” |
| Great | 很好 | 绿色 `#50C391` | “很稳！” |
| Good | 不错 | 黄色 `#E9AB3B` | “再靠近一点” |
| Miss | 未命中 | 灰/红 `#E45756` | “别急，听下一拍” |

### 9.2 即时反馈

- 命中瞬间：判定文字 + 拍点波纹 + 连击数字。
- 早期/晚期：显示 `-18ms 早` 或 `+12ms 晚`，帮助用户自我校正。
- 节拍漏掉：TrainingPad 短暂变暗，连击清零，不惩罚过重。

### 9.3 匹配度

- 实时匹配度保留 1 位小数，实时按“已出现预期节拍”计算，最终按“全部预期节拍”计算，逻辑见技术方案。
- 评级映射：

```text
S: ≥ 97
A: 90–96.9
B: 80–89.9
C: 70–79.9
D: < 70
```

## 10. 视觉设计系统

参考站为暖橙色主色、深色面板、Montserrat 数字字体。StayOnBeat 保留类似气质，但做差异化。

### 10.1 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| `primary` | `#EB825A` | 主按钮、当前拍高亮、品牌强调 |
| `primary-dark` | `#D66C44` | 主按钮 hover/active |
| `bg-dark` | `#21232F` | 暗色背景 |
| `panel-dark` | `#282B3E` | 暗色卡片/面板 |
| `bg-light` | `#F5F7FB` | 亮色背景 |
| `text-primary` | `#1F2430` / `#FFFFFF` | 主文字，按主题 |
| `text-secondary` | `#75798D` | 次级文字 |
| `accent` | `#E9AB3B` | Good / 警告 / 热身 |
| `success` | `#50C391` | Great / 完成状态 |
| `perfect` | `#FFD166` | Perfect 判定 |
| `danger` | `#E45756` | Miss / 停止 |
| `info` | `#6C8EFF` | 链接/辅助 |

### 10.2 字体

- 数字与 BPM：`Montserrat`，`font-variant-numeric: tabular-nums`，保证跳动时宽度稳定。
- 中文正文：系统字体栈 `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 判定词可加粗、短时放大，强调游戏感。

### 10.3 形状与动效

- 卡片圆角 12–16px，按钮圆角 999px。
- 节拍灯用圆形，重音灯放大 1.3 倍。
- 动效原则：命中反馈 ≤ 180ms，节拍脉冲与调度时钟同步；未静音时同时与音频同步，避免长动画影响下一拍。
- 尊重 `prefers-reduced-motion`，关闭非必要动画。

## 11. 响应式策略

- 断点：`<480px`、`<768px`、`<1024px`、`≥1200px`。
- 桌面：TrainingPad 位于中央，控件在下方。
- 移动：TrainingPad 占主要触控区域，控件折叠为抽屉。
- 触摸设备：使用 `pointerdown` 降低点击延迟，禁用双击缩放。

## 12. 可访问性

- 全部控件可键盘操作，焦点状态明显。
- 提供“仅键盘/仅鼠标/混合”输入模式。
- 视觉节拍不能只依赖颜色，需配合形状、位置或符号。
- 支持关闭动画、提高对比度。
- 音量设置明确显示 0%–100%。

## 13. 内容与文案原则

- 简洁、动作导向：主按钮用“开始训练”，而不是“播放”。
- 数字优先，解释后置。
- 不使用参考站原文、Logo、图标或素材。
- 文案键外置，便于后续多语言。

## 14. 指标与验证

### 14.1 产品指标

- 首次训练完成率。
- 平均训练时长。
- 训练后 7 日回访率。
- 设置项使用率（静音、Tap BPM、细分）。
- 匹配度分布，用于校准难度。

### 14.2 体验验收

- 用户无需说明，10 秒内知道如何开始训练。
- 训练中每拍都能感知到“我早/晚了多少”。
- 静音模式下仍能舒适跟随节拍。
- 一次 60 秒训练完整流程不卡顿。

## 16. 设计决策记录

- 默认暗色：参考站亮色为默认，但 StayOnBeat 定位办公室隐蔽训练，暗色更适合专注与低打扰。
- 默认静音：MVP 首次进入静音/仅视觉，开启声音后默认音量 0.5；后续根据用户设置记忆。
- 使用“匹配度”而非“准确率”作为主指标：更符合“跟拍匹配”的产品直觉，但技术口径与准确率一致。
- 判定窗口暂定 40/80/120ms：先上线收集数据，再依据分布调整。

## 17. 后续探索

- 连续节拍序列挑战：每轮随机改变 BPM 或细分。
- “盲拍”训练：关闭视觉，仅凭听觉点击，训练内化拍感。
- 与乐器练习结合：自定义拍号/复拍节奏型。
